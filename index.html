Sprite Sheet Packer

2. Processing options

Each sheet is copied at its original size and is never sliced, scaled, trimmed, or rotated.

Compact packs frames using their actual dimensions. Use the JSON manifest to locate individual frames.

These frames have different source dimensions. Alignment-preserving trim requires matching dimensions, so each frame will be trimmed independently and animation jitter may occur.
